# Skills

Ask in plain words. You can also call a skill by name.

| Skill | Does |
| --- | --- |
| `devkit:new-project` | Starts a project and drafts its PRD |
| `devkit:prd` | Writes or reviews the PRD |
| `devkit:ux` | Writes or updates the UX doc |
| `devkit:design` | Writes or updates the design doc |
| `devkit:plan` | Writes the plan or says what to do next |
| `devkit:implement` | Builds a plan task with tests and docs |
| `devkit:fix-bug` | Fixes a bug, starting from a failing test |
| `devkit:proposal` | Writes a proposal for a change not yet decided |
| `devkit:design-review` | Writes a decided change into the docs for review |
| `devkit:restructure` | Merges, splits or reorders sections without breaking IDs |
| `devkit:analysis` | Writes up what a spike showed |
| `devkit:user-docs` | Writes or updates the user guide |
| `devkit:finish-milestone` | Checks the docs and closes a finished milestone |
| `devkit:release` | Tags a release with its changes |
| `devkit:upgrade` | Brings a project up to the current conventions |
| `devkit:audit` | Finds where a project has drifted from the conventions |
