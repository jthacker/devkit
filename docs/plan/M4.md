# M4. Publish

Install from GitHub for anyone, and keep the checkout route for the maintainer and forks ([Design: Distribution](../design.md#design-fx31)).

**Done when:** someone without a checkout can install devkit from GitHub, start a project, and receive a change through an update.

- [x] **M4.1** Set the plugin version to `8.0.0` and test that its major matches `VERSION` ([Design: Versions](../design.md#design-chm4)). Evolve bumps it.
- [x] **M4.2** Evolve edits nothing on a cached install and offers the project's `AGENTS.md` or a fork instead ([Design: Changing the conventions](../design.md#design-7z28)).
- [x] **M4.3** Read the projects directory from `DEVKIT_PROJECTS_DIR`, falling back to the parent of the current repo, in `status.sh` and `new-project` ([Design: Starting a project](../design.md#design-076f), [Design: Finding drift](../design.md#design-njs0)).
- [x] **M4.4** Start skill descriptions with "In a project that uses devkit", except `new-project`, `upgrade`, `status` and `evolve` ([Design: Plugin structure](../design.md#design-e8ng)).
- [x] **M4.5** Add a CI workflow running `just check` ([Design: Testing](../design.md#design-axx8)).
- [x] **M4.6** README with the GitHub install route, and user docs for installing and forking ([Design: Two ways to install](../design.md#design-er6e), [Design: Forks](../design.md#design-3ycr)).
- [x] **M4.7** Push to the public repo, tag `v8.0.0`, and install from GitHub in a clean environment. Then release a fix as `v8.0.1` and confirm the installed copy updates.
- [ ] **M4.8** Push v2, and check on GitHub and in VS Code that section anchors don't show, that links within and between docs open the section, and that a GitHub autolink per doc opens it ([Design: Headings, links and citations](../design.md#design-bm50)).
