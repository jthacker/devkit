# M4. Publish

Install from GitHub for anyone, and keep the checkout route for the maintainer and forks (D14).

**Done when:** someone without a checkout can install devkit from GitHub, start a project, and receive a change through an update.

- [x] **M4.1** Set the plugin version to `8.0.0` and test that its major matches `VERSION` (D14.1). Evolve bumps it.
- [x] **M4.2** Evolve edits nothing on a cached install and offers the project's `AGENTS.md` or a fork instead (D8).
- [x] **M4.3** Read the projects directory from `DEVKIT_PROJECTS_DIR`, falling back to the parent of the current repo, in `status.sh` and `new-project` (D6, D12.3).
- [x] **M4.4** Start skill descriptions with "In a project that uses devkit", except `new-project`, `upgrade`, `status` and `evolve` (D5).
- [x] **M4.5** Add a CI workflow running `just check` (D9).
- [x] **M4.6** README with the GitHub install route, and user docs for installing and forking (D14.2, D14.3).
- [x] **M4.7** Push to the public repo, tag `v8.0.0`, and install from GitHub in a clean environment. Then release a fix as `v8.0.1` and confirm the installed copy updates.
