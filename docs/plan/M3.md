# M3. Adopt in existing projects

**Done when:** each project the user chooses records the current conventions version and its docs follow them.

- [ ] **M3.1** Decide which projects adopt, and settle the questions in [Design: Open questions](../design.md#design-b2ea).
- [ ] **M3.2** Adopt in one project with `devkit:upgrade` from v0, and refine the v1 migration from what it shows.
- [ ] **M3.3** Adopt in the rest, one at a time, running `devkit:audit` after each.
