# M2. Trial on a new project

Use devkit for real before changing anything that exists.

**Done when:** a new project has gone from one request through PRD, design and plan with devkit's skills, and what needed fixing has been fixed with `evolve`.

- [ ] **M2.1** Install the plugin, or use `just run`, and start a throwaway project with `devkit:new-project`. Check the result against D6.
- [ ] **M2.2** Take a real new project through PRD, design and plan.
- [ ] **M2.3** Write a proposal and decide it with `devkit:design-review`. Check the planned sections and plan afterward.
- [ ] **M2.4** Make one convention change with `evolve` and upgrade the trial project with `devkit:upgrade`, to test D7 and D8 end to end.
- [ ] **M2.5** Implement a task with `devkit:implement` and fix a bug with `devkit:fix-bug` in the trial project, and check the commits and docs against D12.
